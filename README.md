# Tinywork Agent Office

Standalone interactive 2D animated virtual AI-agent office prototype.

## Demo

Open GitHub Pages once enabled: https://beautygoldjelly-rgb.github.io/tinywork-agent-office/

## Controls

Select an agent and assign Coding, Riset, Testing, or Istirahat. Pause and Reset control the animation.

This is a **frontend animation simulation**, not a live AI backend. All PNG spritesheets are embedded directly into `index.html`; no build tooling or dependencies needed.
